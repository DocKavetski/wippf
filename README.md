# WIPPF 2.0 — клиницистский подсчёт

Висбаденский опросник позитивной психотерапии и семейной терапии (Peseschkian & Deidenbach, 1988; Remmers, 2009).

Локальное приложение для клинициста: ввод **строки из 88 цифр (1–4)** или заполнение **бланка**, мгновенный профиль 27 шкал и обобщённых измерений a/r/k, e/w/i.

## Запуск

```bash
npm install
npm run dev
```

Сборка одного `dist/index.html` (можно открыть с диска):

```bash
npm run build
```

Онлайн: https://dockavetski.github.io/wippf/

## Ответы

| Цифра | Значение   |
|------:|------------|
| 4     | Да         |
| 3     | Скорее да  |
| 2     | Скорее нет |
| 1     | Нет        |

Ориентиры шкал: **3–5** слабо, **6–9** баланс, **10–12** выражено. Не диагноз.

Данные хранятся только в `localStorage` браузера.
